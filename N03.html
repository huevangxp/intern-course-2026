LESSON 03 • Data Fetching & State

ບົດທີ 3: Data Fetching ແລະ State Management

ຮຽນຮູ້ການດຶງຂໍ້ມູນຈາກ API ດ້ວຍ useFetch() ແບບ SSR-friendly, ການຈັດການ Global State ດ້ວຍ useState(), ແລະ ການສ້າງ Server API Endpoints.

1 ການດຶງຂໍ້ມູນດ້ວຍ useFetch()

useFetch ເປັນ Composable ຫຼັກຂອງ Nuxt ສຳລັບດຶງຂໍ້ມູນທັງຝັ່ງ Server ແລະ Client ໂດຍປ້ອງກັນການ Fetch ຊ້ຳຊ້ອນ (Double Data Fetching):

app/pages/products.vue 
<script setup lang="ts">
// useFetch ຈະ Return: data, pending (loading), error, refresh
const { data: products, pending, error, refresh } = await useFetch('https://api.example.com/products')
</script>

<template>
  <div class="p-6 space-y-4">
    <h1 class="text-2xl font-bold text-white">ລາຍການສິນຄ້າ</h1>
    
    <div v-if="pending" class="text-teal-400 font-semibold">ກຳລັງໂຫຼດຂໍ້ມູນ...</div>
    <div v-else-if="error" class="text-rose-400">ເກີດຂໍ້ຜິດພາດ: {{ error.message }}</div>
    
    <div v-else class="grid grid-cols-1 sm:grid-cols-2 gap-4">
      <div v-for="item in products" :key="item.id" class="p-4 border border-slate-800 rounded-xl bg-[#0c1220] shadow-sm">
        <h3 class="font-bold text-white">{{ item.title }}</h3>
        <p class="text-teal-400 font-bold mt-1">{{ item.price }} ₭</p>
      </div>
    </div>
  </div>
</template>

2 ການຈັດການ Global State ດ້ວຍ useState()

useState ເປັນ SSR-friendly Ref ທີ່ແບ່ງປັນ State ລະຫວ່າງ Components ແລະ ສົ່ງຕໍ່ຄ່າຈາກ Server ໄປຍັງ Browser ໄດ້ຢ່າງປອດໄພ:

app/composables/useCart.ts 
export const useCart = () => {
  // ສ້າງ Global State ຊື່ 'cart-count'
  const cartCount = useState<number>('cart-count', () => 0)

  const addToCart = () => cartCount.value++
  const resetCart = () => cartCount.value = 0

  return { cartCount, addToCart, resetCart }
}
