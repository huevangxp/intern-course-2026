1 Axios ແມ່ນຫຍັງ? ແລະ ເປັນຫຍັງຈຶ່ງເລືອກໃຊ້ໃນ Nuxt 4?

Axios ແມ່ນ Promise-based HTTP Client ຍອດນິຍົມທີ່ສຸດໃນວົງການ JavaScript & Vue.js. ເຖິງແມ່ນວ່າ Nuxt 4 ຈະມີ useFetch() ແລະ $fetch ແຕ່ Axios ຍັງມີຈຸດເດັ່ນສະເພາະທີ່ຫຼາຍບໍລິສັດ ແລະ ໂຄງການຂະໜາດໃຫຍ່ເລືອກໃຊ້:

🛡️

Request & Response Interceptors

ແນບ JWT Token ອັດຕະໂນມັດ ແລະ ດັກຈັບ 401 Unauthorized ຫຼື Refresh Token ໄດ້ງ່າຍດາຍ.

⚙️

Custom Instance & BaseURL

ຕັ້ງຄ່າ Base URL, Headers, Timeout ແລະ Config ສະເພາະຫຼາຍໆ Services ໄດ້ຢ່າງເປັນລະບົບ.

🔄

Auto JSON Transformation

ແປງຂໍ້ມູນ Request ແລະ Response ເປັນ JSON ອັດຕະໂນມັດ ໂດຍບໍ່ຕ້ອງເອີ້ນໃຊ້ response.json().

ຄຸນສົມບັດ (Feature) Axios useFetch / $fetch (Nuxt Native)
Interceptors (ດັກຈັບ Request/Response) ✅ ສະດວກຫຼາຍ (Native Interceptors API) ⚠️ ໃຊ້ຜ່ານ onRequest / onResponse hooks
Upload & Download Progress Tracking ✅ ຮອງຮັບ onUploadProgress ❌ ບໍ່ຮອງຮັບໂດຍກົງ
Request Cancellation ✅ AbortController & CancelToken ✅ AbortSignal
SSR Payload De-duplication ⚠️ ຕ້ອງລະວັງການ fetch ຊ້ຳສອງຮອບ ✅ ຈັດການໃຫ້ອັດຕະໂນມັດໃນ SSR

3 ສ້າງ Axios Instance & Plugin ໃນ Nuxt 4

ເພື່ອຄວາມສະດວກໃນການເອີ້ນໃຊ້ທົ່ວທັງໂປຣເຈັກ ແລະ ການແນບ Authentication Token, ພວກເຮົາຈະສ້າງ Nuxt Plugin ໄວ້ທີ່ app/plugins/axios.ts:

app/plugins/axios.ts 
import axios from 'axios'

export default defineNuxtPlugin((nuxtApp) => {
  // 1. ສ້າງ Axios Instance ພ້ອມ Base URL
  const api = axios.create({
    baseURL: 'https://api.example.com/v1', // ຫຼື ໃຊ້ useRuntimeConfig().public.apiBaseUrl
    timeout: 10000,
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json'
    }
  })

  // 2. Request Interceptor: ແນບ Bearer Token ອັດຕະໂນມັດ
  api.interceptors.request.use(
    (config) => {
      const token = useCookie('auth_token').value // ດຶງ Token ຈາກ Cookie
      if (token) {
        config.headers.Authorization = `Bearer ${token}`
      }
      return config
    },
    (error) => Promise.reject(error)
  )

  // 3. Response Interceptor: ດັກຈັບ Error ທົ່ວລະບົບ
  api.interceptors.response.use(
    (response) => response,
    (error) => {
      if (error.response?.status === 401) {
        console.error('Session Expired, Redirecting to Login...')
        navigateTo('/login')
      }
      return Promise.reject(error)
    }
  )

  // 4. Inject ໃຫ້ໃຊ້ຜ່ານ nuxtApp.$api ຫຼື useNuxtApp().$api
  return {
    provide: {
      api: api
    }
  }
})

🌟 Composable Pattern ແນະນຳ: app/composables/useApi.ts

ນອກຈາກ Plugin ແລ້ວ, ທ່ານຍັງສາມາດສ້າງ Composable ເພື່ອໃຫ້ Vue 3 Script Setup ເອີ້ນໃຊ້ໄດ້ຢ່າງວ່ອງໄວ: 

export const useApi = () => {
  const { $api } = useNuxtApp()
  return $api
}

4 ວິທີດຶງຂໍ້ມູນ (GET Request) ໃນ Vue 3 & Nuxt 4

ການດຶງຂໍ້ມູນດ້ວຍ Axios ຈະໃຊ້ຮູບແບບ async / await ພ້ອມຈັດການ Loading State ແລະ Error Handling:

Vue 3 Script Setup Data Fetching Pattern 
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import axios from 'axios'

// 1. Reactive State ສຳລັບເກັບຂໍ້ມູນ, ສະຖານະໂຫຼດ ແລະ Error
const teachers = ref<any[]>([])
const isLoading = ref(false)
const errorMessage = ref('')

// 2. Function ດຶງຂໍ້ມູນຄູ-ອາຈານດ້ວຍ Axios GET
const fetchTeachers = async () => {
  isLoading.value = true
  errorMessage.value = ''

  try {
    const response = await axios.get('https://jsonplaceholder.typicode.com/users')
    // ເກັບຂໍ້ມູນລົງ State (response.data ຄື Body JSON ທີ່ Axios parse ໃຫ້ແລ້ວ)
    teachers.value = response.data
  } catch (error: any) {
    console.error('Error fetching teachers:', error)
    errorMessage.value = error.response?.data?.message || 'ບໍ່ສາມາດດຶງຂໍ້ມູນໄດ້, ກະລຸນາກວດສອບການເຊື່ອມຕໍ່'
  } finally {
    isLoading.value = false // ຢຸດສະຖານະ Loading ສະເໝີ
  }
}

// 3. ເອີ້ນເຮັດວຽກເມື່ອ Component Mount
onMounted(() => {
  fetchTeachers()
})
</script>

const departments = [

  'Computer Science',
  'Information Technology',
  'Mathematics',
  'English Language'
]

// Fetch Data ດ້ວຍ Axios
const fetchTeachers = async () => {
  isLoading.value = true
  errorMessage.value = ''
  try {
    const res = await axios.get('https://api.example.com/teachers')
    teachers.value = res.data
  } catch (err: any) {
    errorMessage.value = err.message || 'ເກີດຂໍ້ຜິດພາດໃນການດຶງຂໍ້ມູນ'
  } finally {
    isLoading.value = false
  }
}

// Filtered Teachers
const filteredTeachers = computed(() => {
  return teachers.value.filter((item) => {
    const matchDept = selectedDept.value === 'ທັງໝົດ' || item.department === selectedDept.value
    const matchQuery = item.name.toLowerCase().includes(searchQuery.value.toLowerCase()) ||
                       item.subject.toLowerCase().includes(searchQuery.value.toLowerCase())
    return matchDept && matchQuery
  })
})

onMounted(() => {
  fetchTeachers()
})
</script>

1️⃣ ຄວນ Fetch ໃນ Client-Side ເມື່ອໃຊ້ Axios ໃນ Page Components

ຖ້າຕ້ອງການດຶງຂໍ້ມູນໃນຕອນ Server-Side Rendering (SSR) ໂດຍບໍ່ໃຫ້ເກີດການ Fetch ຊ້ຳ 2 ເທື່ອ (Double Fetching), ແນະນຳໃຫ້ໃຊ້ useAsyncData() ຄອບ Axios: 

const { data: teachers } = await useAsyncData('teachers-key', () => 
  axios.get('/api/teachers').then(res => res.data)
)
2️⃣ ຈັດການ Base URL ຜ່ານ nuxt.config.ts

ຢ່າຂຽນ Hardcode URL ລົງໃນ Component ໂດຍກົງ. ໃຫ້ຕັ້ງຄ່າໃນ runtimeConfig.public.apiBaseUrl ເພື່ອໃຫ້ສາມາດປ່ຽນລະຫວ່າງ Development, Staging, ແລະ Production ໄດ້ສະດວກ.

3️⃣ ກວດສອບ Cleanup / Cancel Tokens ເມື່ອ Unmount
