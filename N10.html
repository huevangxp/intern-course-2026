3 ສ້າງ Store ຕົວຢ່າງ: app/stores/teacher.ts

ໃນ Nuxt 4, ໂຟລເດີ app/stores/ ຈະຖືກ **Auto-Import** ອັດຕະໂນມັດ ໂດຍບໍ່ຕ້ອງ import `defineStore`:

app/stores/teacher.ts (Setup Store Syntax) 
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useTeacherStore = defineStore('teacher', () => {
  // 1. STATE (Reactive State)
  const bookmarkedTeachers = ref<any[]>([])
  const activeDepartment = ref<string>('all')

  // 2. GETTERS (Computed Properties)
  const totalBookmarks = computed(() => bookmarkedTeachers.value.length)
  const isBookmarked = computed(() => {
    return (id: number) => bookmarkedTeachers.value.some(t => t.id === id)
  })

  // 3. ACTIONS (Functions for Modifying State)
  function toggleBookmark(teacher: any) {
    const index = bookmarkedTeachers.value.findIndex(t => t.id === teacher.id)
    if (index > -1) {
      bookmarkedTeachers.value.splice(index, 1) // Remove
    } else {
      bookmarkedTeachers.value.push(teacher) // Add
    }
  }

  function clearAllBookmarks() {
    bookmarkedTeachers.value = []
  }

  return {
    bookmarkedTeachers,
    activeDepartment,
    totalBookmarks,
    isBookmarked,
    toggleBookmark,
    clearAllBookmarks
  }
})

7 ໂຄດຕົວຢ່າງສົມບູນ: ການເອີ້ນໃຊ້ Pinia Store ໃນ Component

ການນຳໃຊ້ storeToRefs() ເພື່ອດຶງ State ແລະ Getters ໂດຍບໍ່ເສຍຄຸນສົມບັດ Reactivity:

app/pages/teachers/bookmarks.vue 
<script setup lang="ts">
import { storeToRefs } from 'pinia'
import { useTeacherStore } from '~/stores/teacher'

// 1. Instantiation Store
const teacherStore = useTeacherStore()

// 2. ໃຊ້ storeToRefs ສຳລັບ State & Getters (ເພື່ອຮັກສາ Reactivity)
const { bookmarkedTeachers, totalBookmarks } = storeToRefs(teacherStore)

// 3. Actions ສາມາດ Destructure ໄດ້ໂດຍກົງ
const { toggleBookmark, clearAllBookmarks } = teacherStore
</script>

<template>
  <v-container class="py-8">
    <h1 class="text-h5 font-weight-bold mb-4">
      ອາຈານທີ່ບັນທຶກໄວ້ ({{ totalBookmarks }})
    </h1>

    <v-row v-if="bookmarkedTeachers.length">
      <v-col v-for="teacher in bookmarkedTeachers" :key="teacher.id" cols="12" sm="6">
        <v-card class="p-4 rounded-xl" elevation="2">
          <div class="d-flex justify-space-between align-center">
            <div>
              <h4 class="font-weight-bold">{{ teacher.name }}</h4>
              <p class="text-caption text-medium-emphasis">{{ teacher.department }}</p>
            </div>
            <v-btn icon="mdi-star" color="warning" variant="text" @click="toggleBookmark(teacher)" />
          </div>
        </v-card>
      </v-col>
    </v-row>
  </v-container>
</template>

8 Best Practices & ຂໍ້ຄວນລະວັງໃນການໃຊ້ Pinia

⚠️ ຢ່າ Destructure State ໂດຍກົງໂດຍບໍ່ໃຊ້ storeToRefs()

ຖ້າທ່ານຂຽນ const { bookmarkedTeachers } = teacherStore, ຄຸນສົມບັດ Reactivity ຈະຂາດທັນທີເມື່ອ State ມີການປ່ຽນແປງ. ຕ້ອງໃຊ້ storeToRefs(teacherStore) ສະເໝີ!

💡 ແຍກ Store ຕາມ Domain / Feature

ຢ່າລວມທຸກຢ່າງໄວ້ໃນ Store ດຽວ. ໃຫ້ແບ່ງເປັນ useAuthStore(), useTeacherStore(), useCartStore() ເພື່ອໃຫ້ງ່າຍຕໍ່ການຮັກສາ.
