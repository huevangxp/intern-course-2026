1 SEO ໃນ Nuxt 4: ເປັນຫຍັງ SSR ຈຶ່ງເປັນກະສັດຂອງ Search Engines?

ໃນ Single Page Application (SPA ທຳມະດາ), Google Bot ຈະເຫັນພຽງແຕ່ <div id="app"></div> ວ່າງເປົ່າ. ແຕ່ໃນ Nuxt 4 Server-Side Rendering (SSR), Server ຈະ Render HTML ສົມບູນພ້ອມ Meta Tags ສົ່ງອອກໄປ, ເຮັດໃຫ້ Google, Facebook, ແລະ Twitter ສາມາດ Index ເນື້ອຫາ ແລະ ສະແດງຮູບພາບ Preview ໄດ້ 100%!

4 ຄຳສັ່ງ Build ສຳລັບ Production Server

SSR Mode (Node.js / Docker)

`nuxi build`

ສ້າງ Bundle ໄວ້ທີ່ .output/ ສຳລັບ Run ດ້ວຍ Node.js Server.

npx nuxi build
node .output/server/index.mjs
Static Site (SSG)

`nuxi generate`

Pre-render ທຸກໜ້າອອກມາເປັນ Static HTML Files ໄວ້ທີ່ .output/public/.

npx nuxi generate

5 Production Dockerfile ສຳລັບ Nuxt 4

Dockerfile (Multi-Stage Build) 
# 1. Build Stage
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 2. Production Runner Stage
FROM node:20-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
ENV PORT=3000
COPY --from=builder /app/.output ./

EXPOSE 3000
CMD ["node", "server/index.mjs"]
