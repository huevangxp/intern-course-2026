ບົດທີ 6: Form Handling, v-model ແລະ ການສະແດງຜົນຂໍ້ມູນ

ຮຽນຮູ້ການຮັບຄ່າຈາກຟອມດ້ວຍ v-model, ການສ້າງ Reactive State ດ້ວຍ const formData = reactive({...}), ແລະ ການກົດປຸ່ມເພື່ອສະແດງຜົນຂໍ້ມູນ Input ທັນທີ.

1 ຫຼັກການເຮັດວຽກຂອງ Form ໃນ Nuxt 4 / Vue 3

ໃນ Nuxt 4 (Vue 3 Composition API), ການເຊື່ອມຕໍ່ຂໍ້ມູນລະຫວ່າງ Input Elements ແລະ JavaScript State ໃຊ້ລະບົບ Two-Way Data Binding ຜ່ານ Directive v-model:

🔄

v-model Two-Way Binding

ເມື່ອຜູ້ໃຊ້ພິມຂໍ້ຄວາມ, ຄ່າໃນຕົວປ່ຽນ `const` ຈະອັບເດດທັນທີ ແລະ ໃນທາງກັບກັນຫາກປ່ຽນຄ່າໃນໂຄດ Input ກໍຈະປ່ຽນຕາມ.

📦

reactive() vs ref()

ສຳລັບ Form ທີ່ມີຫຼາຍ Fields ແນະນຳໃຫ້ໃຊ້ `reactive({ name: '', email: '' })` ເພື່ອຮວບຮວມຂໍ້ມູນໄວ້ໃນ Object ດຽວ.

⚡

@submit.prevent

ປ້ອງກັນບໍ່ໃຫ້ Browser Reload ໜ້າຈໍໃໝ່ ເພື່ອໃຫ້ Vue ປະມວນຜົນ ແລະ ສະແດງຜົນຂໍ້ມູນໄດ້ແບບ Single Page App.

2 ວິທີປະກາດ const form ແລະ ຟັງຊັນກົດປຸ່ມ

ສ້າງຕົວປ່ຽນ Reactive State ເພື່ອຮັບຄ່າ ແລະ ຕົວປ່ຽນສຳລັບເກັບຂໍ້ມູນທີ່ກົດບັນທຶກແລ້ວ:

Script Composition Setup
// 1. ປະກາດ Form State & Submitted State
const form = reactive({
  fullName: '',
  email: '',
  level: 'ເລີ່ມຕົ້ນ',
  message: ''
})
// 2. ຕົວປ່ຽນເກັບຂໍ້ມູນຫຼັງຈາກກົດປຸ່ມ Show Data
const submittedData = ref<typeof form | null>(null)
// 3. ຟັງຊັນເມື່ອກົດປຸ່ມ Submit / Show
const handleShowData = () => {
  submittedData.value = { ...form }
}

            4
            ໂຄດຕົວຢ່າງສົມບູນໃນ Nuxt 4 Component (app/pages/form-demo.vue)
          

          
ທ່ານສາມາດນຳໂຄດນີ້ໄປວາງໄວ້ໃນໂປຣເຈັກ Nuxt 4 ເພື່ອສ້າງໜ້າ Form ທີ່ສົມບູນແບບ:


          

            

              

                
                
                
                app/pages/form-demo.vue
              

              
            

            
<script setup lang="ts">
// 1. ສ້າງ Reactive Form Object ດ້ວຍ const
const formData = reactive({
  fullName: '',
  email: '',
  level: 'Beginner',
  message: ''
})

// 2. ຕົວປ່ຽນເກັບຂໍ້ມູນທີ່ກົດ Submit ແລ້ວ
const submittedData = ref<typeof formData | null>(null)
const isSubmitted = ref(false)

// 3. ຟັງຊັນກົດປຸ່ມ Show Data
const handleSubmit = () => {
  // Clone ຂໍ້ມູນຈາກ formData ມາເກັບໄວ້ໃນ submittedData
  submittedData.value = { ...formData }
  isSubmitted.value = true
}

// 4. ຟັງຊັນລ້າງຄ່າ Reset
const handleReset = () => {
  formData.fullName = ''
  formData.email = ''
  formData.level = 'Beginner'
  formData.message = ''
  submittedData.value = null
  isSubmitted.value = false
}
</script>

<template>
  <div class="max-w-4xl mx-auto p-6 space-y-6">
    <h1 class="text-3xl font-bold text-white">ແບບຟອມຮັບຄ່າ Nuxt 4</h1>

    <form @submit.prevent="handleSubmit" class="space-y-4 bg-[#0c1220] p-6 border border-slate-800 rounded-2xl shadow-xl">
      <div>
        <label class="block text-sm font-bold text-slate-300">ຊື່:</label>
        <input v-model="formData.fullName" required class="w-full bg-[#050811] border border-slate-700 p-2.5 rounded-xl text-white mt-1 focus:outline-none focus:border-teal-400" />
      </div>

      <div>
        <label class="block text-sm font-bold text-slate-300">ອີເມວ:</label>
        <input v-model="formData.email" type="email" required class="w-full bg-[#050811] border border-slate-700 p-2.5 rounded-xl text-white mt-1 focus:outline-none focus:border-teal-400" />
      </div>

      <div>
        <label class="block text-sm font-bold text-slate-300">ລະດັບ:</label>
        <select v-model="formData.level" class="w-full bg-[#050811] border border-slate-700 p-2.5 rounded-xl text-white mt-1 focus:outline-none focus:border-teal-400">
          <option>Beginner</option>
          <option>Intermediate</option>
          <option>Advanced</option>
        </select>
      </div>

      <div>
        <label class="block text-sm font-bold text-slate-300">ຂໍ້ຄວາມ:</label>
        <textarea v-model="formData.message" rows="3" class="w-full bg-[#050811] border border-slate-700 p-2.5 rounded-xl text-white mt-1 focus:outline-none focus:border-teal-400"></textarea>
      </div>

      <div class="flex gap-3 pt-2">
        <button type="submit" class="bg-teal-500 hover:bg-teal-400 text-slate-950 px-6 py-2.5 rounded-xl font-bold shadow-md shadow-teal-500/25 transition">
          ສະແດງຜົນຂໍ້ມູນ (Show Data)
        </button>
        <button type="button" @click="handleReset" class="bg-slate-800 hover:bg-slate-700 text-slate-300 px-4 py-2.5 rounded-xl font-bold border border-slate-700 transition">
          Reset
        </button>
      </div>
    </form>

    <!-- ສະແດງຜົນຂໍ້ມູນເມື່ອກົດ Submit ແລ້ວ -->
    <div v-if="isSubmitted && submittedData" class="bg-[#0c1220] border border-slate-800 text-white p-6 rounded-2xl space-y-2 shadow-xl">
      <h2 class="text-xl font-bold text-teal-400">ຂໍ້ມູນທີ່ໄດ້ຮັບ (Submitted Data):</h2>
      <p class="text-slate-300"><strong class="text-white">ຊື່:</strong> {{ submittedData.fullName }}</p>
      <p class="text-slate-300"><strong class="text-white">ອີເມວ:</strong> {{ submittedData.email }}</p>
      <p class="text-slate-300"><strong class="text-white">ລະດັບ:</strong> {{ submittedData.level }}</p>
      <p class="text-slate-300"><strong class="text-white">ຂໍ້ຄວາມ:</strong> {{ submittedData.message }}</p>
    </div>
  </div>
</template>
