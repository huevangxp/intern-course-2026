ບົດທີ 6: Form Handling, v-model ແລະ ການສະແດງຜົນຂໍ້ມູນ

ຮຽນຮູ້ການຮັບຄ່າຈາກຟອມດ້ວຍ v-model, ການສ້າງ Reactive State ດ້ວຍ const formData = reactive({...}), ແລະ ການກົດປຸ່ມເພື່ອສະແດງຜົນຂໍ້ມູນ Input ທັນທີ.

1 ຫຼັກການເຮັດວຽກຂອງ Form ໃນ Nuxt 4 / Vue 3

ໃນ Nuxt 4 (Vue 3 Composition API), ການເຊື່ອມຕໍ່ຂໍ້ມູນລະຫວ່າງ Input Elements ແລະ JavaScript State ໃຊ້ລະບົບ Two-Way Data Binding ຜ່ານ Directive v-model:

🔄

v-model Two-Way Binding

ເມື່ອຜູ້ໃຊ້ພິມຂໍ້ຄວາມ, ຄ່າໃນຕົວປ່ຽນ `const` ຈະອັບເດດທັນທີ ແລະ ໃນທາງກັບກັນຫາກປ່ຽນຄ່າໃນໂຄດ Input ກໍຈະປ່ຽນຕາມ.

📦

reactive() vs ref()

ສຳລັບ Form ທີ່ມີຫຼາຍ Fields ແນະນຳໃຫ້ໃຊ້ `reactive({ name: '', email: '' })` ເພື່ອຮວບຮວມຂໍ້ມູນໄວ້ໃນ Object ດຽວ.

⚡

@submit.prevent

ປ້ອງກັນບໍ່ໃຫ້ Browser Reload ໜ້າຈໍໃໝ່ ເພື່ອໃຫ້ Vue ປະມວນຜົນ ແລະ ສະແດງຜົນຂໍ້ມູນໄດ້ແບບ Single Page App.

2 ວິທີປະກາດ const form ແລະ ຟັງຊັນກົດປຸ່ມ

ສ້າງຕົວປ່ຽນ Reactive State ເພື່ອຮັບຄ່າ ແລະ ຕົວປ່ຽນສຳລັບເກັບຂໍ້ມູນທີ່ກົດບັນທຶກແລ້ວ:

// 1. ປະກາດ Form State & Submitted State
const form = reactive({
  fullName: '',
  email: '',
  level: 'ເລີ່ມຕົ້ນ',
  message: ''
})
// 2. ຕົວປ່ຽນເກັບຂໍ້ມູນຫຼັງຈາກກົດປຸ່ມ Show Data
const submittedData = ref<typeof form | null>(null)
// 3. ຟັງຊັນເມື່ອກົດປຸ່ມ Submit / Show
const handleShowData = () => {
  submittedData.value = { ...form }
}

ທົດລອງຕື່ມຂໍ້ມູນລົງໃນຟອມດ້ານລຸ່ມ ແລ້ວກົດປຸ່ມ "ສະແດງຜົນຂໍ້ມູນ (Show Data)" ເພື່ອເບິ່ງການດຶງຄ່າຈາກ const ມາສະແດງຜົນທັນທີ:

            4
            ໂຄດຕົວຢ່າງສົມບູນໃນ Nuxt 4 Component (app/pages/form-demo.vue)
          

          
ທ່ານສາມາດນຳໂຄດນີ້ໄປວາງໄວ້ໃນໂປຣເຈັກ Nuxt 4 ເພື່ອສ້າງໜ້າ Form ທີ່ສົມບູນແບບ:


          

            

              app/pages/form-demo.vue
              
            

            
<script setup lang="ts">
// 1. ສ້າງ Reactive Form Object ດ້ວຍ const
const formData = reactive({
  fullName: '',
  email: '',
  level: 'Beginner',
  message: ''
})

// 2. ຕົວປ່ຽນເກັບຂໍ້ມູນທີ່ກົດ Submit ແລ້ວ
const submittedData = ref<typeof formData | null>(null)
const isSubmitted = ref(false)

// 3. ຟັງຊັນກົດປຸ່ມ Show Data
const handleSubmit = () => {
  // Clone ຂໍ້ມູນຈາກ formData ມາເກັບໄວ້ໃນ submittedData
  submittedData.value = { ...formData }
  isSubmitted.value = true
}

// 4. ຟັງຊັນລ້າງຄ່າ Reset
const handleReset = () => {
  formData.fullName = ''
  formData.email = ''
  formData.level = 'Beginner'
  formData.message = ''
  submittedData.value = null
  isSubmitted.value = false
}
</script>

<template>
  <div class="max-w-4xl mx-auto p-6 space-y-6">
    <h1 class="text-3xl font-bold text-slate-900">ແບບຟອມຮັບຄ່າ Nuxt 4</h1>

    <form @submit.prevent="handleSubmit" class="space-y-4 bg-white p-6 border rounded-2xl shadow">
      <div>
        <label class="block text-sm font-bold">ຊື່:</label>
        <input v-model="formData.fullName" required class="w-full border p-2 rounded mt-1" />
      </div>

      <div>
        <label class="block text-sm font-bold">ອີເມວ:</label>
        <input v-model="formData.email" type="email" required class="w-full border p-2 rounded mt-1" />
      </div>

      <div>
        <label class="block text-sm font-bold">ລະດັບ:</label>
        <select v-model="formData.level" class="w-full border p-2 rounded mt-1">
          <option>Beginner</option>
          <option>Intermediate</option>
          <option>Advanced</option>
        </select>
      </div>

      <div>
        <label class="block text-sm font-bold">ຂໍ້ຄວາມ:</label>
        <textarea v-model="formData.message" rows="3" class="w-full border p-2 rounded mt-1"></textarea>
      </div>

      <div class="flex gap-3">
        <button type="submit" class="bg-rose-500 hover:bg-rose-600 text-white px-6 py-2.5 rounded-xl font-bold">
          ສະແດງຜົນຂໍ້ມູນ (Show Data)
        </button>
        <button type="button" @click="handleReset" class="bg-slate-200 px-4 py-2.5 rounded-xl font-bold">
          Reset
        </button>
      </div>
    </form>

    <!-- ສະແດງຜົນຂໍ້ມູນເມື່ອກົດ Submit ແລ້ວ -->
    <div v-if="isSubmitted && submittedData" class="bg-slate-900 text-white p-6 rounded-2xl space-y-2">
      <h2 class="text-xl font-bold text-rose-400">ຂໍ້ມູນທີ່ໄດ້ຮັບ (Submitted Data):</h2>
      <p><strong>ຊື່:</strong> {{ submittedData.fullName }}</p>
      <p><strong>ອີເມວ:</strong> {{ submittedData.email }}</p>
      <p><strong>ລະດັບ:</strong> {{ submittedData.level }}</p>
      <p><strong>ຂໍ້ຄວາມ:</strong> {{ submittedData.message }}</p>
    </div>
  </div>
</template>
