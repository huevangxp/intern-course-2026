LESSON 05 • Material Design 3 & Vuetify

ບົດທີ 5: ການຕິດຕັ້ງ ແລະ ໃຊ້ງານ Vuetify 3 ໃນ Nuxt 4

ຮຽນຮູ້ວິທີຕິດຕັ້ງ Vuetify 3, ການເຊື່ອມໂຍງລະບົບ Material Design Icons (MDI), ການຕັ້ງຄ່າ Plugin ໃນ app/plugins/vuetify.ts ແລະ ການນຳໃຊ້ Components ເຊັ່ນ <v-btn>, <v-card>, <v-text-field>.

1 Vuetify 3 ແມ່ນຫຍັງ?

Vuetify 3 ແມ່ນ UI Component Framework ຍອດນິຍົມອັນດັບ 1 ສຳລັບ Vue 3 ແລະ Nuxt ເຊິ່ງຖືກອອກແບບຕາມມາດຕະຖານ Google Material Design 3. ມັນຊ່ວຍໃຫ້ນັກພັດທະນາສ້າງລະບົບ Admin Dashboard, Enterprise App ແລະ Web UI ທີ່ສວຍງາມ ແລະ ມີ Component ຄົບຖ້ວນໂດຍບໍ່ຕ້ອງຂຽນ CSS ເອງທັງໝົດ.

2 ຂັ້ນຕອນການຕິດຕັ້ງ Vuetify 3 ໃນ Nuxt ໂປຣເຈັກ

ເປີດ Terminal ໃນໂຟລເດີໂປຣເຈັກ Nuxt 4 ແລ້ວຕິດຕັ້ງ vuetify, sass ແລະ ໄອຄອນ @mdi/font:

Terminal (npm / pnpm) 
npm i vuetify sass @mdi/font
💡 ທາງເລືອກ (Nuxt Module):

ທ່ານຍັງສາມາດຕິດຕັ້ງຜ່ານ Nuxt Module ທາງການໄດ້ເຊັ່ນກັນ: npx nuxi module add vuetify-nuxt-module

3 ສ້າງ Plugin app/plugins/vuetify.ts ແລະ ຕັ້ງຄ່າ

ສ້າງໄຟລ໌ Plugin ເພື່ອລົງທະບຽນ Vuetify ເຂົ້າສູ່ Nuxt App Lifecycle:

app/plugins/vuetify.ts 
import '@mdi/font/css/materialdesignicons.css'
import 'vuetify/styles'
import { createVuetify } from 'vuetify'
import * as components from 'vuetify/components'
import * as directives from 'vuetify/directives'

export default defineNuxtPlugin((nuxtApp) => {
  const vuetify = createVuetify({
    ssr: true,
    components,
    directives,
    theme: {
      defaultTheme: 'light',
      themes: {
        light: {
          colors: {
            primary: '#4F46E5',   // Indigo
            secondary: '#06B6D4', // Cyan
            success: '#10B981',   // Emerald
            warning: '#F59E0B',   // Amber
            error: '#EF4444',     // Red
          }
        }
      }
    }
  })

  // ລົງທະບຽນ Vuetify ເຂົ້າສູ່ Vue Instance
  nuxtApp.vueApp.use(vuetify)
})

ຕໍ່ມາ, ເພີ່ມການຕັ້ງຄ່າ Build ໃນ nuxt.config.ts:

nuxt.config.ts 
export default defineNuxtConfig({
  compatibilityDate: '2027-01-01',
  css: [
    'vuetify/styles',
    '@mdi/font/css/materialdesignicons.css'
  ],
  build: {
    transpile: ['vuetify']
  }
})

4 ຕົວຢ່າງການນຳໃຊ້ Material Components ໃນ Nuxt

ໃນ Nuxt Template ໃຫ້ຄອບ Component ທັງໝົດດ້ວຍ <v-app> ສະເໝີ ເພື່ອໃຫ້ Theme ແລະ Font ເຮັດວຽກຖືກຕ້ອງ:

app/pages/vuetify-demo.vue 
<template>
  <v-app>
    <v-container class="pa-6">
      <!-- 1. Material Buttons -->
      <v-btn color="primary" prepend-icon="mdi-check" class="mr-3">
        ປຸ່ມ Primary
      </v-btn>
      <v-btn variant="outlined" color="secondary">
        ປຸ່ມ Outlined
      </v-btn>

      <!-- 2. Material Card -->
      <v-card class="mt-6 pa-4" elevation="4" rounded="lg">
        <v-card-title class="font-weight-bold">
          🚀 ຍິນດີຕ້ອນຮັບສູ່ Nuxt 4 + Vuetify 3
        </v-card-title>
        <v-card-text>
          ພັດທະນາ Web Application ດ້ວຍ Material Design Components ແບບງ່າຍດາຍ.
        </v-card-text>
        <v-card-actions>
          <v-btn color="primary" variant="text">ອ່ານເພີ່ມເຕີມ</v-btn>
        </v-card-actions>
      </v-card>

      <!-- 3. Material Text Field -->
      <v-text-field
        label="ຊື່ຜູ້ໃຊ້ງານ (Username)"
        prepend-inner-icon="mdi-account"
        variant="outlined"
        class="mt-6"
      />
    </v-container>
  </v-app>
</template>
