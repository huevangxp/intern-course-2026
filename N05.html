1 Vuetify 3 ແມ່ນຫຍັງ?

Vuetify 3 ແມ່ນ UI Component Framework ຍອດນິຍົມອັນດັບ 1 ສຳລັບ Vue 3 ແລະ Nuxt ເຊິ່ງຖືກອອກແບບຕາມມາດຕະຖານ Google Material Design 3. ມັນມີ Component ສຳເລັດຮູບໃຫ້ໃຊ້ຫຼາຍກວ່າ 100 ຕົວ — ເຮົາພຽງແຕ່ເອົາມາປະກອບກັນ ບໍ່ຕ້ອງຂຽນ CSS ເອງທັງໝົດ.

ເປີດ Terminal ໃນໂຟລເດີໂປຣເຈັກ Nuxt 4 ແລ້ວຕິດຕັ້ງ vuetify, sass ແລະ ໄອຄອນ @mdi/font:

3 ສ້າງ Plugin app/plugins/vuetify.ts ແລະ ຕັ້ງຄ່າ

ສ້າງໄຟລ໌ Plugin ເພື່ອລົງທະບຽນ Vuetify ເຂົ້າສູ່ Nuxt App Lifecycle:

app/plugins/vuetify.ts 
import '@mdi/font/css/materialdesignicons.css'
import 'vuetify/styles'
import { createVuetify } from 'vuetify'
import * as components from 'vuetify/components'
import * as directives from 'vuetify/directives'

export default defineNuxtPlugin((nuxtApp) => {
  const vuetify = createVuetify({
    ssr: true,
    components,
    directives,
    theme: {
      defaultTheme: 'dark',
      themes: {
        dark: {
          colors: {
            primary: '#14b8a6',   // Vibrant Teal
            secondary: '#06b6d4', // Cyan
            success: '#10b981',   // Emerald
            warning: '#f59e0b',   // Amber
            error: '#ef4444',     // Red
            surface: '#0c1220',   // Dark Surface
          }
        }
      }
    }
  })

  // ລົງທະບຽນ Vuetify ເຂົ້າສູ່ Vue Instance
  nuxtApp.vueApp.use(vuetify)
})

ຕໍ່ມາ, ເພີ່ມການຕັ້ງຄ່າ Build ໃນ nuxt.config.ts:

nuxt.config.ts 
export default defineNuxtConfig({
  compatibilityDate: '2027-01-01',
  css: [
    'vuetify/styles',
    '@mdi/font/css/materialdesignicons.css'
  ],
  build: {
    transpile: ['vuetify']
  }
})
⚠️ ຢ່າລືມ! ໃນ Template ຕ້ອງຄອບທຸກຢ່າງດ້ວຍ <v-app> ສະເໝີ (ແນະນຳໃສ່ໄວ້ໃນ app/app.vue ຫຼື Layout) ເພື່ອໃຫ້ Theme ເຮັດວຽກຖືກຕ້ອງ.

5.1 ຫົວຂໍ້ & ຂໍ້ຄວາມ (Title & Text)

Vuetify ມີ Typography Classes ສຳເລັດຮູບໃຫ້ຈັດຂະໜາດຕົວໜັງສື — ບໍ່ຕ້ອງຂຽນ CSS ເອງ. ໃຊ້ໄດ້ກັບທຸກ Tag ຜ່ານ class:

app/pages/text-demo.vue 
<template>
  <v-container>
    <!-- ຫົວຂໍ້ຂະໜາດຕ່າງໆ (ໃຫຍ່ → ນ້ອຍ: text-h1 ຮອດ text-h6) -->
    <h1 class="text-h3 font-weight-bold">ຫົວຂໍ້ໃຫຍ່</h1>
    <h2 class="text-h5 text-teal">ຫົວຂໍ້ຮອງ (ໃສ່ສີໄດ້)</h2>

    <!-- ຂໍ້ຄວາມທຳມະດາ -->
    <p class="text-body-1">ຂໍ້ຄວາມທຳມະດາ ໃຊ້ກັບເນື້ອຫາທົ່ວໄປ</p>
    <p class="text-caption text-grey">ຂໍ້ຄວາມນ້ອຍ ໃຊ້ກັບໝາຍເຫດ</p>
  </v-container>
</template>

5.2 v-card — ການ໌ດສະແດງຂໍ້ມູນ

5.3 v-text-field — ຊ່ອງກອກຂໍ້ມູນ

<v-text-field> ຄືຊ່ອງໃຫ້ຜູ້ໃຊ້ພິມຂໍ້ມູນ (ຊື່, ອີເມວ, ລະຫັດຜ່ານ). ຈຸດສຳຄັນຄື v-model — ມັນຜູກຄ່າທີ່ພິມເຂົ້າກັບຕົວແປໂດຍອັດຕະໂນມັດ:

app/pages/input-demo.vue 
<script setup>
// ຕົວແປເກັບຄ່າທີ່ຜູ້ໃຊ້ພິມ
const username = ref('')
const password = ref('')
</script>

<template>
  <v-container>
    <v-text-field
      v-model="username"
      label="ຊື່ຜູ້ໃຊ້"
      variant="outlined"
      prepend-inner-icon="mdi-account"

    />

    <!-- ຄ່າຈະປ່ຽນຕາມທັນທີທີ່ພິມ -->
    <p>ສະບາຍດີ: {{ username }}</p>
  </v-container>
</template>

5.5 v-btn — ປຸ່ມກົດ

<v-btn> ຄືປຸ່ມສຳເລັດຮູບ ມີ Ripple Effect ໃນຕົວ. ປັບ ສີ ດ້ວຍ color ແລະ ຮູບແບບ ດ້ວຍ variant:

app/pages/btn-demo.vue 
<template>
  <v-container>
    <!-- ສີຕ່າງໆ -->
    <v-btn color="primary">ບັນທຶກ</v-btn>
    <v-btn color="error">ລຶບ</v-btn>
    <v-btn color="success">ຢືນຢັນ</v-btn>

    <!-- ຮູບແບບຕ່າງໆ (variant) -->
    <v-btn variant="outlined" color="primary">ຂອບຢ່າງດຽວ</v-btn>
    <v-btn variant="text" color="primary">ຕົວໜັງສືຢ່າງດຽວ</v-btn>
    <v-btn variant="tonal" color="primary">ສີຈາງ</v-btn>

    <!-- ໃສ່ໄອຄອນ + ຈັບ Event Click -->
    <v-btn color="primary" prepend-icon="mdi-content-save" @click="save()">
      ບັນທຶກຂໍ້ມູນ
    </v-btn>
  </v-container>
</template>
👀 ຜົນລັບທີ່ໄດ້
ບັນທຶກ ລຶບ ຢືນຢັນ ຂອບຢ່າງດຽວ ຕົວໜັງສືຢ່າງດຽວ ສີຈາງ
💡 ໃຊ້ຕອນໃດ: elevated (ຄ່າເລີ່ມຕົ້ນ) = ປຸ່ມຫຼັກ, outlined = ປຸ່ມຮອງ, text = ປຸ່ມຍົກເລີກ/ລິ້ງ.

5.6 v-select — ເລືອກຈາກລາຍການ

<v-select> ຄື Dropdown ໃຫ້ຜູ້ໃຊ້ເລືອກຄ່າຈາກລາຍການ. ສົ່ງລາຍການເຂົ້າຜ່ານ :items ແລະ ຮັບຄ່າທີ່ເລືອກຜ່ານ v-model:

app/pages/select-demo.vue 
<script setup>
const province = ref(null)   // ຄ່າທີ່ຖືກເລືອກ
const provinces = [          // ລາຍການທັງໝົດ
  'ນະຄອນຫຼວງວຽງຈັນ',
  'ຫຼວງພະບາງ',
  'ສະຫວັນນະເຂດ',
  'ຈຳປາສັກ'
]
</script>

<template>
  <v-container>
    <v-select
      v-model="province"
      :items="provinces"
      label="ເລືອກແຂວງ"
      variant="outlined"
    />

    <p v-if="province">✅ ທ່ານເລືອກ: {{ province }}</p>
  </v-container>
</template>
👀 ຜົນລັບທີ່ໄດ້ (ລອງເລືອກເບິ່ງ!)

5.7 v-dialog — Popup ຢືນຢັນ

<v-dialog> ຄືປ່ອງ Popup ທີ່ເດັ້ງຂຶ້ນກາງຈໍ — ນິຍົມໃຊ້ຢືນຢັນກ່ອນລຶບຂໍ້ມູນ. ຫຼັກການ: ໃຊ້ຕົວແປ dialog ເປັນສະວິດ ເປີດ (true) / ປິດ (false):

app/pages/dialog-demo.vue 
<script setup>
const dialog = ref(false)  // false = ປິດຢູ່
</script>

<template>
  <v-container>
    <!-- ກົດປຸ່ມ → ປ່ຽນເປັນ true → Popup ເປີດ -->
    <v-btn color="error" @click="dialog = true">ລຶບຂໍ້ມູນ</v-btn>

    <v-dialog v-model="dialog" max-width="400">
      <v-card color="surface">
        <v-card-title>ຢືນຢັນການລຶບ 🗑️</v-card-title>
        <v-card-text>ທ່ານແນ່ໃຈບໍວ່າຕ້ອງການລຶບຂໍ້ມູນນີ້?</v-card-text>
        <v-card-actions>
          <v-spacer />
          <v-btn variant="text" @click="dialog = false">ຍົກເລີກ</v-btn>
          <v-btn color="error" @click="dialog = false">ລຶບເລີຍ</v-btn>
        </v-card-actions>
      </v-card>
    </v-dialog>
  </v-container>
</template>
👀 ຜົນລັບທີ່ໄດ້ (ກົດປຸ່ມທົດລອງ!)
ຢືນຢັນການລຶບ 🗑️
ທ່ານແນ່ໃຈບໍວ່າຕ້ອງການລຶບຂໍ້ມູນນີ້?

5.8 v-table — ຕາຕະລາງຂໍ້ມູນ

<v-table> ຄືຕາຕະລາງແບບ Material Design — ຂຽນຄື HTML Table ທຳມະດາ ແຕ່ໄດ້ Style ງາມທັນທີ. ນິຍົມໃຊ້ຄູ່ກັບ v-for ເພື່ອວົນສະແດງຂໍ້ມູນ:

app/pages/table-demo.vue 
<script setup>
const students = [
  { id: 1, name: 'ສົມຊາຍ', grade: 'A'  },
  { id: 2, name: 'ວັນດີ',  grade: 'B+' },
  { id: 3, name: 'ບຸນມີ',  grade: 'A-' },
]
</script>

<template>
  <v-table theme="dark">
    <thead>
      <tr>
        <th>ລຳດັບ</th>
        <th>ຊື່</th>
        <th>ເກຣດ</th>
      </tr>
    </thead>
    <tbody>
      <!-- ວົນສະແດງນັກຮຽນທີລະຄົນ -->
      <tr v-for="s in students" :key="s.id">
        <td>{{ s.id }}</td>
        <td>{{ s.name }}</td>
        <td>{{ s.grade }}</td>
      </tr>
    </tbody>
  </v-table>
</template>
👀 ຜົນລັບທີ່ໄດ້
ລຳດັບ ຊື່ ເກຣດ
1ສົມຊາຍA
2ວັນດີB+
3ບຸນມີA-
💡 ຂັ້ນສູງ: ຖ້າຢາກໄດ້ຕາຕະລາງທີ່ ຄົ້ນຫາ + ຈັດລຽງ + ແບ່ງໜ້າ ໄດ້ໃນຕົວ ໃຫ້ໃຊ້ <v-data-table> (ຈະໄດ້ຮຽນຕອນເຮັດໂປຣເຈັກຈິງ).

📝 ສະຫຼຸບບົດຮຽນ

ຢາກເຮັດຫຍັງ? ໃຊ້ Component ໃດ?
ຫົວຂໍ້ / ຂໍ້ຄວາມຂະໜາດຕ່າງໆclass="text-h1 ... text-caption"
ຫຸ້ມຂໍ້ມູນເປັນກຸ່ມສວຍໆv-card (+ title, text, actions)
ຮັບຂໍ້ມູນຈາກຜູ້ໃຊ້v-text-field + v-model
ຈັດ Layout / Responsivev-row + v-col (12 ຖັນ)
ປຸ່ມກົດv-btn + color + variant
ເລືອກຈາກລາຍການv-select + :items
Popup ຢືນຢັນv-dialog + v-model
ຕາຕະລາງຂໍ້ມູນv-table + v-for
✏️ ແບບຝຶກຫັດທ້າຍບົດ: ສ້າງໜ້າລົງທະບຽນນັກຮຽນ

ນຳ Component ທັງໝົດທີ່ຮຽນມາປະກອບກັນເປັນໜ້າດຽວ:

  1. ໃຊ້ v-card ຫຸ້ມຟອມ ພ້ອມ v-card-title ຂຽນວ່າ "ລົງທະບຽນນັກຮຽນ"
  2. ໃສ່ v-text-field 2 ອັນ: ຊື່ ແລະ ເບີໂທ (ຈັດຄຽງກັນດ້ວຍ v-row/v-col)
  3. ໃສ່ v-select ໃຫ້ເລືອກຫ້ອງຮຽນ (A, B, C)
  4. ກົດປຸ່ມ v-btn "ບັນທຶກ" ແລ້ວໃຫ້ v-dialog ເດັ້ງຂຶ້ນຢືນຢັນ
  5. ທ້າທາຍ 🔥: ສະແດງລາຍຊື່ນັກຮຽນທີ່ລົງທະບຽນແລ້ວດ້ວຍ v-table
