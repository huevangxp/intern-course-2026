ບົດທີ 11: Teacher Full CRUD Operations (Create, Read, Update, Delete)

ຮຽນຮູ້ການສ້າງລະບົບຈັດການຂໍ້ມູນຄູ-ອາຈານແບບຄົບວົງຈອນ (Full CRUD): ການເພີ່ມ (Create / POST), ການສະແດງ (Read / GET), ການແກ້ໄຂ (Update / PUT), ແລະ ການລຶບ (Delete / DELETE) ພ້ອມ Dialog Popups ແລະ Feedback Notifications.

1 CRUD ແມ່ນຫຍັງ? ແລະ ການຈັບຄູ່ກັບ HTTP Methods

CRUD ຄື 4 ການກະທຳພື້ນຖານທີ່ສຸດຂອງທຸກໆ Web Application ໃນການໂຕ້ຕອບກັບຖານຂໍ້ມູນ (Database):

POST
Create (ສ້າງ/ເພີ່ມ)

ສົ່ງ Body JSON ໄປບັນທຶກຂໍ້ມູນຄູໃໝ່ລົງ DB

GET
Read (ອ່ານ/ດຶງ)

ດຶງລາຍຊື່ທັງໝົດ ຫຼື ສະເພາະ ID ທີ່ເລືອກ

PUT / PATCH
Update (ແກ້ໄຂ)

ອັບເດດຂໍ້ມູນຊື່, ພາກວິຊາ, ຫຼື ສະຖານະ

DELETE
Delete (ລຶບ)

ລຶບ Record ອອກຈາກລະບົບພ້ອມຢືນຢັນ

2 CRUD API Request Handlers ດ້ວຍ Axios / `$fetch`

Teacher CRUD Service Functions 
// 1. CREATE: ເພີ່ມຄູໃໝ່ (POST)
const createTeacher = async (teacherData) => {
  return await $fetch('/api/teachers', {
    method: 'POST',
    body: teacherData
  })
}

// 2. READ: ດຶງລາຍຊື່ (GET)
const getTeachers = async () => {
  return await $fetch('/api/teachers')
}

// 3. UPDATE: ແກ້ໄຂຂໍ້ມູນ (PUT)
const updateTeacher = async (id, updatedData) => {
  return await $fetch(`/api/teachers/${id}`, {
    method: 'PUT',
    body: updatedData
  })
}

// 4. DELETE: ລຶບຂໍ້ມູນ (DELETE)
const deleteTeacher = async (id) => {
  return await $fetch(`/api/teachers/${id}`, {
    method: 'DELETE'
  })
}

7 ໂຄດຕົວຢ່າງສົມບູນ: app/pages/teachers/crud.vue

app/pages/teachers/crud.vue 
<script setup lang="ts">
import { ref } from 'vue'

const teachers = ref([])
const isDialogOpen = ref(false)
const isEditing = ref(false)
const form = ref({ id: null, name: '', department: '', subject: '' })

// Save (Create or Update)
const handleSave = async () => {
  if (isEditing.value) {
    await $fetch(`/api/teachers/${form.value.id}`, { method: 'PUT', body: form.value })
  } else {
    await $fetch('/api/teachers', { method: 'POST', body: form.value })
  }
  isDialogOpen.value = false
}

// Delete
const handleDelete = async (id) => {
  if (confirm('ທ່ານແນ່ໃຈບໍ່ວ່າຕ້ອງການລຶບຂໍ້ມູນອາຈານທ່ານນີ້?')) {
    await $fetch(`/api/teachers/${id}`, { method: 'DELETE' })
  }
}
</script>
