LESSON 05.0 • Classic Data Rendering

ບົດທີ 5.0: ການສະແດງຜົນຂໍ້ມູນແບບດັ້ງເດີມ (Show Old Data)

ຮຽນຮູ້ວິທີການສະແດງຜົນຂໍ້ມູນ Array / Object ແບບເກົ່າໃນ Vue 3 ໂດຍໃຊ້ Standard HTML Table, Unordered Lists (<ul><li>) ແລະ Custom CSS, ພ້ອມວິເຄາະຂໍ້ຈຳກັດກ່ອນທີ່ຈະປ່ຽນມາໃຊ້ Material UI Components.

1 ວິທີການສະແດງຜົນຂໍ້ມູນແບບດັ້ງເດີມ (Traditional Data Render)

ກ່ອນທີ່ຈະມີ UI Component Frameworks ເຊັ່ນ Vuetify, ນັກພັດທະນາມັກຈະສະແດງຂໍ້ມູນທີ່ດຶງມາຈາກ Backend ຜ່ານ 3 ຮູບແບບຫຼັກ:

📊

HTML Table ທຳມະດາ

ໃຊ້ <table><tr><td> ຄູ່ກັບ v-for. ຕ້ອງຂຽນ CSS ປັບ Border ແລະ Padding ເອງ.

📋

List Item Elements

ໃຊ້ <ul> <li> ສະແດງລາຍການຂໍ້ຄວາມຕໍ່ໆກັນແບບແຖວຕັ້ງ.

📦

Div Boxes + Manual CSS

ສ້າງ <div class="box"> ພ້ອມຂຽນ CSS Shadow, Radius, Hover ດ້ວຍຕົນເອງ.

2 ຂໍ້ຈຳກັດຂອງການສະແດງຜົນຂໍ້ມູນແບບເກົ່າ

⚠️

ບໍ່ຮອງຮັບ Responsive ສົມບູນແບບ

Table ທຳມະດາຈະລົ້ນຈໍມືຖື (Horizontal Overflow) ຖ້າບໍ່ມີການຂຽນ CSS Media Queries ສະເພາະ.

⚠️

ຂາດ Micro-Interactions ແລະ Theme Dynamic

ບໍ່ມີ Ripple Effects, Elevation Shadows, Skeleton Loading, ຫຼື Dark Mode ທີ່ປັບປ່ຽນໄດ້ທັນທີ.

💡

ວິທີແກ້ໄຂທີ່ທັນສະໄໝ:

ໃນບົດຕໍ່ໄປ (N05.1), ພວກເຮົາຈະປ່ຽນມາໃຊ້ <v-card> ດ້ວຍ Teal Theme ທີ່ສວຍງາມ ແລະ ຮອງຮັບ Responsive ທຸກຂະໜາດຈໍ.
