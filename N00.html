ບົດທີ 0: ແນະນຳກ່ຽວກັບ Nuxt 4 (Introduction)

ເຂົ້າໃຈວ່າ Nuxt ແມ່ນຫຍັງ, ເປັນຫຍັງຈຶ່ງຖືກເອີ້ນວ່າ The Intuitive Vue Framework, ແລະ Nuxt 4 ຍົກລະດັບການພັດທະນາ Full-Stack ແນວໃດ.

1 Nuxt 4 ແມ່ນຫຍັງ?

Nuxt ແມ່ນ Open-Source Web Framework ທີ່ສ້າງຂຶ້ນເທິງ Vue 3. ຖ້າ Vue 3 ເປັນເຄື່ອງມືສ້າງ User Interface ທີ່ວ່ອງໄວ, Nuxt ຈະເປັນໂຕຊ່ວຍຈັດການທຸກສິ່ງທີ່ຈຳເປັນສຳລັບການສ້າງແອັບພລິເຄຊັນລະດັບ Production ເຊັ່ນ: Routing, Server-Side Rendering (SSR), API Endpoints, State Management, ແລະ SEO.

⚡

Auto-Imports ອັດຕະໂນມັດ

Composables (`ref`, `computed`, `useFetch`) ແລະ Components ທັງໝົດຖືກ Import ອັດຕະໂນມັດ ໂດຍບໍ່ຕ້ອງຂຽນ `import` ເອງ.

📂

File-Based Routing

ພຽງແຕ່ສ້າງໄຟລ໌ `.vue` ໄວ້ໃນໂຟລເດີ `app/pages/`, Nuxt ຈະສ້າງ Route ໜ້າເວັບໃຫ້ອັດຕະໂນມັດ.

🚀

Nitro Server Engine

ມີ Server Engine ນ້ຳໜັກເບົາ ແລະ ໄວທີ່ສຸດໃນຕົວ ສາມາດສ້າງ Backend API ໄດ້ໃນໂຟລເດີ `server/api/`.

🌐

SEO & Meta Tags

ຮອງຮັບການເຮັດ Search Engine Optimization ຕັ້ງແຕ່ເລີ່ມຕົ້ນຜ່ານ `useSeoMeta()` ແລະ Server Rendering.

2 ຮູບແບບການ Render ໃນ Nuxt 4 (Rendering Modes)

Nuxt 4 ສາມາດປັບປ່ຽນຮູບແບບການສະແດງຜົນໄດ້ຕາມຄວາມເໝາະສົມຂອງແຕ່ລະໜ້າວຽກ:

1. Server-Side Rendering (SSR) ຄ່າເລີ່ມຕົ້ນ (Default)

ເຊີບເວີຈະປະມວນຜົນ HTML ສົ່ງໄປໃຫ້ Browser ທັນທີ ເຮັດໃຫ້ໂຫຼດໜ້າເວັບໄດ້ໄວ ແລະ ຕິດອັນດັບ Google SEO ໄດ້ງ່າຍ.

2. Static Site Generation (SSG / Pre-rendering) npx nuxi generate

ສ້າງເປັນໄຟລ໌ HTML ຄົງທີ່ຕອນ Build ສາມາດນຳໄປຝາກໄວ້ເທິງ CDN ຟຣີເຊັ່ນ Cloudflare Pages, Vercel, Netlify ໄດ້ງ່າຍດາຍ.

3. Single Page Application (SPA / Client-Only) ssr: false

ເຮັດວຽກເທິງ Browser ຄືກັບ Vue ແບບດັ້ງເດີມ ເໝາະສຳລັບລະບົບຫຼັງບ້ານ (Admin Dashboard) ທີ່ບໍ່ຕ້ອງການ SEO.

3 ປຽບທຽບ Vue 3 ທຳມະດາ vs. Nuxt 4

ຄຸນສົມບັດ Vue 3 ທຳມະດາ Nuxt 4
Routing ຕ້ອງຂຽນ `vue-router` ເອງ ອັດຕະໂນມັດຈາກໂຟລເດີ `app/pages/`
Rendering Client-Side (SPA) ເທົ່ານັ້ນ Universal (SSR, SSG, SPA, ISR)
Backend API ຕ້ອງຂຽນ Express / Node ແຍກ ມີ Nitro API Routes ໃນ `server/api/`
Imports ຕ້ອງ `import { ref } from 'vue'` Auto-import ບໍ່ຕ້ອງຂຽນ import
