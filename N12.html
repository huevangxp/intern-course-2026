ບົດທີ 12: Nitro Server Engine & API Routes ຂັ້ນສູງ

ຮຽນຮູ້ການຂຽນ Backend RESTful APIs ພາຍໃນ Nuxt 4 ດ້ວຍ Nitro Engine, ການສ້າງ Event Handlers ໃນ server/api/, ການອ່ານ Request Body ແລະ Params ດ້ວຍ H3 Utilities, ການເຊື່ອມຕໍ່ຖານຂໍ້ມູນ (Prisma ORM / SQLite), ແລະ Server Middleware.

1 Nitro Engine ແມ່ນຫຍັງ? ແລະ ຄວາມສາມາດໃນ Nuxt 4.6+

Nitro ຄື Next-Generation Server Engine ທີ່ຝັງຢູ່ໃນ Nuxt. ມັນປ່ຽນໃຫ້ Nuxt ບໍ່ແມ່ນພຽງແຕ່ Frontend UI ແຕ່ກາຍເປັນ Universal Full-Stack Web Framework ທີ່ສາມາດ Deploy ລົງ Node.js, Docker, Serverless (Vercel, AWS Lambda) ຫຼື Edge Workers (Cloudflare) ໄດ້ໂດຍບໍ່ຕ້ອງແກ້ໄຂໂຄດ. ໃນ Nuxt 4.6+, ໂຄດ Server ຍັງໄດ້ຮັບການອັບເກຣດເປັນ nuxt/server ອີກດ້ວຍ.

⚡

Zero-Config API Routes

ພຽງແຕ່ສ້າງໄຟລ໌ໃນ server/api/ ລະບົບຈະສ້າງ REST Endpoint ໃຫ້ອັດຕະໂນມັດ.

🎯

End-to-End Type Safety

Return Type ຈາກ Server API ຈະຖືກສົ່ງຕໍ່ໄປຍັງ $fetch ໃນ Frontend ແບບອັດຕະໂນມັດ.

🔒

Server Security

Database Credentials ແລະ API Secret Keys ຈະຖືກເກັບໄວ້ສະເພາະຝັ່ງ Server ເທົ່ານັ້ນ ບໍ່ຫຼຸດໄປ Client.

2 ໂຄງສ້າງ Server Directory Anatomy

my-nuxt-project/
├── server/
├── api/ # REST Endpoints (prefix /api/...)
├── teachers/
├── index.get.ts # GET /api/teachers
├── index.post.ts # POST /api/teachers
└── [id].get.ts # GET /api/teachers/:id
├── middleware/ # Server request loggers, auth tokens
├── routes/ # Custom non-prefixed routes (e.g. /sitemap.xml)
└── utils/ # Database client, shared server helpers

3 H3 Utilities: ການອ່ານ Request Body, Query & Params

server/api/teachers/[id].get.ts 
export default defineEventHandler(async (event) => {
  // 1. ດຶງ Route Param: /api/teachers/:id
  const id = getRouterParam(event, 'id')

  // 2. ດຶງ Query Params: ?include=courses
  const query = getQuery(event)

  // 3. ກວດສອບຄວາມຖືກຕ້ອງ
  if (!id || isNaN(Number(id))) {
    throw createError({
      statusCode: 400,
      statusMessage: 'Bad Request: Teacher ID ຕ້ອງເປັນຕົວເລກເທົ່ານັ້ນ'
    })
  }

  // 4. Return Data (Nitro ຈະແປງເປັນ JSON Response ອັດຕະໂນມັດ)
  return {
    success: true,
    data: {
      id: Number(id),
      name: "ອຈ. ສົມສັກ ວົງໄຊ",
      department: "Computer Science",
      requestedAt: new Date().toISOString()
    }
  }
})
