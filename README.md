## 🎨 ດີໄຊນ໌ & ຮູບແບບ (Design System: Teal + Dark)

- **Canvas Background**: Deep Nocturnal (`#070b12`)
- **Card / Surface Background**: Sleek Dark Surface (`#0c1220`)
- **Primary Accent**: Vibrant Teal (`#14b8a6` / `#2dd4bf`)
- **Typography**: Google Fonts (*Noto Sans Lao*, *Plus Jakarta Sans*, *JetBrains Mono*)
- **Global Theme Stylesheet**: `theme.css`

---

## 🛠️ ເຕັກໂນໂລຊີທີ່ນຳໃຊ້ (Tech Stack)

- **Framework**: Nuxt 4 (v4.6.2+) & Vue 3.5+
- **Server Engine**: Nitro 3+ (`nuxt/server` Server-Agnostic)
- **UI & Components**: Vuetify 3 (Material Design 3) & Material Design Icons (`@mdi/font`)
- **Styling**: Tailwind CSS CDN & Custom CSS Design System (`theme.css`)
- **State Management**: Pinia (`@pinia/nuxt`) & `useState`
- **HTTP Client**: Axios & Rebuilt Typed `$fetch` / `useFetch`
- **Fonts**: Noto Sans Lao & Plus Jakarta Sans & JetBrains Mono

## 💻 ວິທີເປີດໃຊ້ງານ (Getting Started)

ໂປຣເຈັກນີ້ເປັນ **Static Web Portal** ສາມາດເປີດໃຊ້ງານໄດ້ທັນທີໂດຍບໍ່ຕ້ອງ Build:
1. ເປີດໄຟລ໌ `index.html` ໃນ Web Browser (Google Chrome, Microsoft Edge, Safari).
2. ເລືອກຮຽນບົດຮຽນຕັ້ງແຕ່ **N00** ຈົນເຖິງ **N13** ຕາມລຳດັບ.
