ບົດທີ 1: ຕິດຕັ້ງໂປຣເຈັກ Nuxt 4 (Installation & Setup)

ກຽມສະພາບແວດລ້ອມ, ສ້າງໂປຣເຈັກໃໝ່ດ້ວຍ Nuxi CLI, ສຳຫຼວດໂຄງສ້າງໂຟລເດີ ແລະ Run Server ທົດສອບການເຮັດວຽກ.

1 ສິ່ງທີ່ຕ້ອງກຽມພ້ອມ (Prerequisites)

Node.js Version
v18.20.0+ ຫຼື v20.9.0+
ກວດສອບດ້ວຍ: `node -v`
Package Manager
pnpm / npm / bun
ແນະນຳໃຫ້ໃຊ້ pnpm ເພາະໄວທີ່ສຸດ
Code Editor
VS Code / Cursor
ຕິດຕັ້ງສ່ວນເສີມ Vue - Official

2 ຂັ້ນຕອນການສ້າງໂປຣເຈັກດ້ວຍ Nuxi CLI

ຂັ້ນຕອນທີ 1: ສັ່ງສ້າງໂປຣເຈັກຜ່ານ Terminal
$ npx nuxi@latest init my-nuxt4-app
ຂັ້ນຕອນທີ 2: ເຂົ້າໄປໃນໂຟລເດີໂປຣເຈັກ
$ cd my-nuxt4-app
ຂັ້ນຕອນທີ 3: ເປີດ Dev Server ທົດສອບການເຮັດວຽກ
$ pnpm dev

ຫຼັງຈາກນັ້ນເປີດ Browser ໄປທີ່: http://localhost:3000

3 ໂຄງສ້າງໂຟລເດີຂອງ Nuxt 4 (Directory Anatomy)

// ໂຄງສ້າງຫຼັກຂອງ Nuxt 4
my-nuxt4-app/
├── app/ # ໂຟລເດີຫຼັກສຳລັບ Vue & Frontend UI
│ ├── app.vue # Component ຫຼັກຂອງແອັບ
│ ├── pages/ # ໜ້າເວັບ Routing ອັດຕະໂນມັດ
│ ├── components/ # Vue Components (Auto-Import)
│ ├── composables/ # State & Logic ທີ່ໃຊ້ຮ່ວມກັນ
│ └── layouts/ # Layouts ຂອງໜ້າເວັບ
├── server/ # Nitro Backend API (`server/api/`)
├── public/ # ໄຟລ໌ຮູບພາບ ແລະ Assets ຄົງທີ່
├── nuxt.config.ts # ໄຟລ໌ຕັ້ງຄ່າ Configuration ຫຼັກ
└── package.json

4 ຂຽນໂຄດທຳອິດໃນ app/app.vue

ເປີດໄຟລ໌ app/app.vue ແລະ ທົດລອງຂຽນ Reactive Component ດັ່ງນີ້:

app/app.vue 
<script setup lang="ts">
// Auto-imported State ໃນ Nuxt 4 ບໍ່ຕ້ອງ import ref ເອງ
const count = ref(0)
const title = ref('ສະບາຍດີ Nuxt 4!')

useSeoMeta({
  title: 'My Nuxt 4 App',
  description: 'ສ້າງດ້ວຍ Vue 3.5, Vite & Nuxt 4'
})
</script>

<template>
  <div class="min-h-screen bg-[#070b12] text-white flex flex-col items-center justify-center p-6 text-center space-y-6">
    <h1 class="text-4xl font-bold text-teal-400">{{ title }}</h1>
    <p class="text-slate-400 text-sm">ຍິນດີຕ້ອນຮັບສູ່ການພັດທະນາ Nuxt 4 ພາສາລາວ</p>
    <button 
      @click="count++" 
      class="px-6 py-3 rounded-2xl bg-teal-500 hover:bg-teal-400 text-slate-950 font-bold transition shadow-lg shadow-teal-500/25"
    >
      ກົດປຸ່ມ: {{ count }} ຄັ້ງ
    </button>
  </div>
</template>
