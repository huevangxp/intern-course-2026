ບົດທີ 7: ຕິດຕັ້ງ, ຕັ້ງຄ່າ ແລະ ໃຊ້ງານ Material Design Icons (MDI)

ຮຽນຮູ້ວິທີຕິດຕັ້ງໄອຄອນ @mdi/font, ການເຊື່ອມຕໍ່ກັບ Vuetify 3 ແລະ Nuxt 4, ວິທີເອີ້ນໃຊ້ຜ່ານ <v-icon>, class mdi mdi-*, ການປັບແຕ່ງສີ, ຂະໜາດ ແລະ Animations.

1 Material Design Icons (MDI) ແມ່ນຫຍັງ?

Material Design Icons (MDI) ແມ່ນຄັງໄອຄອນ Vector ມາດຕະຖານສູງກວ່າ 7,000+ ໄອຄອນ ທີ່ຖືກອອກແບບໃຫ້ເຂົ້າກັນໄດ້ຢ່າງສົມບູນແບບກັບ Google Material Design ແລະ Vuetify Framework. ມັນຮອງຮັບທັງແບບ Webfont (`@mdi/font`) ແລະ ແບບ SVG JavaScript Module (`@mdi/js`).

✨

7,000+ Icons ຄົບຖ້ວນ

ກວມເອົາທຸກປະເພດ UI ເຊັ່ນ Navigation, Actions, Social, Files, Hardware, ແລະ E-commerce.

⚡

Vector Scalable

ຄົມຊັດທຸກຂະໜາດຈໍ (Retina Display) ແລະ ສາມາດປ່ຽນສີໄດ້ຄືກັບຕົວໜັງສືຜ່ານ CSS color.

🔌

Vuetify Native Support

ເຊື່ອມໂຍງເຂົ້າກັບ Vuetify ໄດ້ໂດຍອັດຕະໂນມັດ ໂດຍພຽງແຕ່ລະບຸຊື່ໄອຄອນ ເຊັ່ນ mdi-account.

2 ຂັ້ນຕອນການຕິດຕັ້ງ Package @mdi/font

ທ່ານສາມາດຕິດຕັ້ງ Package ຜ່ານ Terminal ໃນໂຟລເດີໂປຣເຈັກຂອງທ່ານ:

ຕິດຕັ້ງຜ່ານ NPM / PNPM 
npm i @mdi/font

* ຫາກທ່ານຕິດຕັ້ງ Vuetify 3 ມາແລ້ວໃນບົດທີ 5, Package ນີ້ຈະຖືກລວມເຂົ້າໃນລະບົບແລ້ວ.

3 ວິທີຕັ້ງຄ່າໃນ nuxt.config.ts ແລະ Vuetify Plugin

1. ນຳເຂົ້າ CSS Stylesheet ຂອງ MDI ໃນ nuxt.config.ts:

nuxt.config.ts 
export default defineNuxtConfig({
  css: [
    '@mdi/font/css/materialdesignicons.css' // Import MDI CSS ທົ່ວທັງເວັບ
  ]
})

2. ຕັ້ງຄ່າ default icon set ໃນ app/plugins/vuetify.ts:

app/plugins/vuetify.ts 
import { createVuetify } from 'vuetify'
import { aliases, mdi } from 'vuetify/iconsets/mdi'

export default defineNuxtPlugin((nuxtApp) => {
  const vuetify = createVuetify({
    icons: {
      defaultSet: 'mdi',
      aliases,
      sets: {
        mdi
      }
    }
  })
  nuxtApp.vueApp.use(vuetify)
})

4 ວິທີເອີ້ນໃຊ້ MDI Icons ໃນ Nuxt & Vue Components

ທ່ານສາມາດນຳໃຊ້ MDI Icons ໄດ້ 3 ຮູບແບບຫຼັກ:

app/pages/icon-examples.vue 
<template>
  <div class="p-6 space-y-6">
    <!-- ແບບທີ 1: ໃຊ້ຜ່ານ Vuetify <v-icon> -->
    <v-icon icon="mdi-home" size="large" color="primary" />
    <v-icon icon="mdi-heart" color="red" />
    <v-icon icon="mdi-bell-ring" size="x-large" color="amber" />

    <!-- ແບບທີ 2: ໃຊ້ໃນ Vuetify Buttons & Text Fields -->
    <v-btn color="primary" prepend-icon="mdi-account-plus">
      ເພີ່ມສະມາຊິກ
    </v-btn>

    <v-text-field
      label="ຄົ້ນຫາຂໍ້ມູນ..."
      prepend-inner-icon="mdi-magnify"
      append-inner-icon="mdi-microphone"
      variant="outlined"
    />

    <!-- ແບບທີ 3: ໃຊ້ຜ່ານ Standard HTML / Tailwind CSS Class -->
    <i class="mdi mdi-github text-3xl text-slate-800 hover:text-emerald-500 transition"></i>
    <i class="mdi mdi-loading mdi-spin text-2xl text-teal-600"></i> <!-- ໄອຄອນໝຸນ Spin -->
  </div>
</template>
