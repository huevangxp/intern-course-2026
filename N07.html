Material Design Icons (MDI) ແມ່ນຫຍັງ?

ພື້ນຖານຄວາມຮູ້ ແລະ ໂຄງສ້າງການເຮັດວຽກພາຍໃນ Nuxt 4

Material Design Icons (MDI) ແມ່ນຄັງໄອຄອນ Vector ມາດຕະຖານສູງກວ່າ 7,000+ ໄອຄອນ ທີ່ຖືກອອກແບບໃຫ້ເຂົ້າກັນໄດ້ຢ່າງສົມບູນແບບກັບ Google Material Design ແລະ Vuetify Framework. ມັນຮອງຮັບທັງແບບ Webfont (@mdi/font) ແລະ ແບບ SVG JavaScript Module (@mdi/js).

ຂັ້ນຕອນການຕິດຕັ້ງ Package @mdi/font

ເລືອກ Package Manager ທີ່ທ່ານນຳໃຊ້ໃນໂປຣເຈັກ

ເປີດ Terminal ໃນໂຟລເດີ Root ຂອງໂປຣເຈັກ Nuxt 4 ແລ້ວເລືອກຕິດຕັ້ງຜ່ານ Package Manager ທີ່ທ່ານຕ້ອງການ:

$ npm i @mdi/font
ໝາຍເຫດສຳຄັນ: ຫາກທ່ານໄດ້ຕິດຕັ້ງ Vuetify 3 ຕາມບົດຮຽນທີ 5 (Lesson 05) ແລ້ວ, Package @mdi/font ອາດຈະຖືກຕິດຕັ້ງເຂົ້າໃນ node_modules ແລ້ວ. ທ່ານພຽງແຕ່ກວດສອບວ່າໄດ້ import CSS ໃນ nuxt.config.ts ແລ້ວຫຼືຍັງ.
3

ວິທີຕັ້ງຄ່າໃນ nuxt.config.ts ແລະ Vuetify Plugin

ຕັ້ງຄ່າ 2 ໄຟລ໌ຫຼັກເພື່ອໃຫ້ໄອຄອນໃຊ້ງານໄດ້ທຸກໜ້າ

1 ໄຟລ໌ nuxt.config.ts (Import MDI CSS Stylesheet): Global CSS
nuxt.config.ts 
export default defineNuxtConfig({
  // 1. ນຳເຂົ້າ MDI CSS ເພື່ອໃຫ້ Browser ໂຫຼດ Font ໄອຄອນ
  css: [
    '@mdi/font/css/materialdesignicons.css'
  ],

  // 2. Transpile Vuetify
  build: {
    transpile: ['vuetify']
  }
})
2 ໄຟລ໌ app/plugins/vuetify.ts (ຕັ້ງຄ່າ Icon Sets): Vuetify Integration
app/plugins/vuetify.ts 
import { createVuetify } from 'vuetify'
import { aliases, mdi } from 'vuetify/iconsets/mdi'

export default defineNuxtPlugin((nuxtApp) => {
  const vuetify = createVuetify({
    ssr: true,
    icons: {
      defaultSet: 'mdi', // ກຳນົດໃຫ້ MDI ເປັນ Icon Set ຫຼັກ
      aliases,
      sets: {
        mdi
      }
    }
  })

  nuxtApp.vueApp.use(vuetify)
})

4 Dynamic Icons ດ້ວຍ Vue Reactivity (`v-bind:icon`)

Reactivity

ປ່ຽນໄອຄອນຕາມເງື່ອນໄຂ State ເຊັ່ນ ປຸ່ມ Like/Favorite, ປຸ່ມສະແດງ/ເຊື່ອງລະຫັດຜ່ານ:

<!-- ປ່ຽນໄອຄອນຫົວໃຈເມື່ອຄລິກ Like -->
<v-icon :icon="isLiked ? 'mdi-heart' : 'mdi-heart-outline'" :color="isLiked ? 'red' : 'grey'" />
<!-- ປ່ຽນໄອຄອນຕາຕອນສະແດງ/ເຊື່ອງລະຫັດຜ່ານ -->

5 ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ & ວິທີແກ້ໄຂ (Troubleshooting)

ແກ້ໄຂບັນຫາທີ່ມັກພົບໃນຕອນຕິດຕັ້ງ ແລະ ໃຊ້ງານ MDI Icons

1. ໄອຄອນສະແດງເປັນຮູບສີ່ຫຼ່ຽມວ່າງເປົ່າ (Square Box / Broken Glyph)

ສາເຫດ: ຍັງບໍ່ໄດ້ Import ໄຟລ໌ CSS ຂອງ MDI ເຂົ້າໃນລະບົບ ຫຼື ຂຽນ path ຜິດ.
ວິທີແກ້ໄຂ: ເຂົ້າໄປເພີ່ມ '@mdi/font/css/materialdesignicons.css' ໃນ array css: [...] ຂອງ nuxt.config.ts ແລ້ວ restart dev server (npm run dev).

2. ຄຳສັ່ງ <v-icon> ບໍ່ສະແດງຫຍັງເລີຍ (Icon Blank)

ສາເຫດ: ບໍ່ໄດ້ກຳນົດ defaultSet: 'mdi' ໃນ plugin Vuetify.
ວິທີແກ້ໄຂ: ໃນ app/plugins/vuetify.ts, ຕ້ອງກວດສອບວ່າມີ icons: { defaultSet: 'mdi', aliases, sets: { mdi } } ຢ່າງຖືກຕ້ອງ.

3. ໄອຄອນບໍ່ກົງແນວກັບຕົວໜັງສື (Vertical Alignment Issue)

ສາເຫດ: ໃນ Flexbox ຂອງ Tailwind CSS, ຕົວໜັງສື ແລະ ໄອຄອນອາດມີ baseline ຕ່າງກັນ.
ວິທີແກ້ໄຂ: ໃສ່ class flex items-center gap-2 ໃນ container ທີ່ຫຸ້ມໄອຄອນ ແລະ ຕົວໜັງສື.

4. SSR Hydration Mismatch ເວລານຳໃຊ້ Dynamic Icons

ສາເຫດ: ການໃຊ້ localStorage ຫຼື window ຕັດສິນຊື່ໄອຄອນກ່ອນທີ່ client ຈະ render.
ວິທີແກ້ໄຂ: ໃຊ້ <ClientOnly> ຫຸ້ມ ຫຼື ໃຊ້ onMounted() ເພື່ອກຳນົດຄ່າ state ເທິງ client.

5. ວິທີຫຼຸດຂະໜາດ Font ສຳລັບ Production Build

ຄຳແນະນຳ: @mdi/font ໃຊ້ໄຟລ໌ font ປະມານ 300KB-400KB ເຊິ່ງເໝາະສົມກັບເວັບທົ່ວໄປ. ແຕ່ຫາກຕ້ອງການ ultra-lightweight, ສາມາດພິຈາລະນາໃຊ້ @nuxt/icon ຮ່ວມກັບ Iconify ເພື່ອດຶງສະເພາະ SVG ທີ່ໃຊ້ຈິງ.
