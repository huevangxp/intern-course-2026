LESSON 02 • Routing & Components

ບົດທີ 2: ໜ້າເວັບ ແລະ Components (Pages & Components)

ຮຽນຮູ້ການສ້າງ Routing ອັດຕະໂນມັດຜ່ານ app/pages/, Dynamic Route Parameters, Layouts ແລະ ການໃຊ້ງານ Vue Components ແບບ Zero-Import.

1 ການສ້າງໜ້າເວັບດ້ວຍ File-Based Routing

ໃນ Nuxt 4, ເມື່ອທ່ານສ້າງໄຟລ໌ `.vue` ໄວ້ໃນໂຟລເດີ app/pages/ ລະບົບຈະສ້າງເສັ້ນທາງ URL ໃຫ້ອັດຕະໂນມັດ:

app/pages/index.vue
ໜ້າຫຼັກ (Route: `/`)

ສະແດງຜົນເມື່ອຜູ້ໃຊ້ເຂົ້າເວັບໄຊທຳອິດ.

app/pages/about.vue
ໜ້າກ່ຽວກັບ (Route: `/about`)

ສະແດງຜົນເມື່ອເຂົ້າໄປທີ່ URL `/about`.

app/pages/courses/[id].vue
Dynamic Route (Route: `/courses/:id`)

ດຶງ Parameter ຜ່ານ `useRoute().params.id`.

<NuxtLink to="/about">
ການເຊື່ອມໂຍງໜ້າເວັບ (Navigation)

ປ່ຽນໜ້າໄດ້ທັນທີໂດຍບໍ່ຕ້ອງ Reload ໜ້າຈໍໃໝ່.

2 ການໃຊ້ງານ Components ແບບ Auto-Import

ທຸກ Component ທີ່ຢູ່ໃນໂຟລເດີ app/components/ ສາມາດເອີ້ນໃຊ້ໃນໜ້າໃດກໍໄດ້ທັນທີ ໂດຍບໍ່ຕ້ອງຂຽນ `import MyComponent from '...'`:

// 1. ສ້າງ Component: app/components/CourseHeader.vue
<template> <h1 class="text-2xl font-bold">{{ title }}</h1> </template>
// 2. ເອີ້ນໃຊ້ໃນ app/pages/index.vue ໄດ້ທັນທີ:
<template> <div> <CourseHeader title="ຍິນດີຕ້ອນຮັບສູ່ Nuxt 4!" /> </div> </template>

3 ລະບົບ Layouts ໃນ app/layouts/

ສ້າງໂຄງຮ່າງໜ້າເວັບຫຼັກເຊັ່ນ Navbar ແລະ Footer ທີ່ໃຊ້ຮ່ວມກັນທຸກໜ້າຜ່ານ app/layouts/default.vue:

// app/layouts/default.vue
<template> <div class="min-h-screen flex flex-col"> <header>Navbar ຮ່ວມກັນທຸກໜ້າ</header> <main class="flex-grow"> <slot /> <!-- ເນື້ອຫາຂອງແຕ່ລະໜ້າຈະມາສະແດງຢູ່ນີ້ --> </main> <footer>Footer ດ້ານລຸ່ມ</footer> </div> </template>
