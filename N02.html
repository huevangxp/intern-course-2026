LESSON 02 • Routing & Components

ບົດທີ 2: ໜ້າເວັບ ແລະ Components (Pages & Components)

ບົດນີ້ຈະສອນວິທີ ສ້າງໜ້າເວັບໃໝ່ ໂດຍພຽງແຕ່ສ້າງໄຟລ໌, ວິທີ ເຊື່ອມແຕ່ລະໜ້າເຂົ້າຫາກັນ ແລະ ວິທີ ແບ່ງໂຄດອອກເປັນຊິ້ນສ່ວນ (Components) ເພື່ອນຳກັບມາໃຊ້ຄືນໄດ້.

🎯 ຮຽນຈົບບົດນີ້ ທ່ານຈະສາມາດ:
  • ✅ ສ້າງໜ້າເວັບໃໝ່ (ເຊັ່ນ ໜ້າ About) ໄດ້ພາຍໃນ 1 ນາທີ
  • ✅ ເຮັດປຸ່ມ/ລິ້ງ ກົດປ່ຽນໜ້າໄດ້ໂດຍບໍ່ Reload ດ້ວຍ <NuxtLink>
  • ✅ ສ້າງ Component ໃຊ້ຊ້ຳໄດ້ຫຼາຍໆໜ້າ ແບບບໍ່ຕ້ອງ Import
  • ✅ ເຮັດ Navbar + Footer ໃຫ້ສະແດງທຸກໜ້າດ້ວຍ Layout <slot />

1 ສ້າງໜ້າເວັບ: ສ້າງໄຟລ໌ = ໄດ້ໜ້າເວັບ ✨

💡 ແນວຄິດງ່າຍໆ

ໃນເວັບແບບເກົ່າ ຖ້າຢາກມີໜ້າໃໝ່ ຕ້ອງໄປຂຽນຕັ້ງຄ່າ Router ເອງ (ຫຍຸ້ງຍາກ). ແຕ່ໃນ Nuxt 4 ພຽງແຕ່ສ້າງໄຟລ໌ .vue ໃສ່ໂຟລເດີ app/pages/ — Nuxt ຈະສ້າງ URL ໃຫ້ອັດຕະໂນມັດທັນທີ!

🏠 ປຽບເໝືອນເຮືອນ: ໂຟລເດີ pages/ ຄືເຮືອນ, ແຕ່ລະໄຟລ໌ຄືແຕ່ລະຫ້ອງ — ສ້າງຫ້ອງໃໝ່ປຸ໊ບ ປະຕູ (URL) ເຂົ້າຫ້ອງນັ້ນກໍເກີດຂຶ້ນເອງ.

ເບິ່ງໂຄງສ້າງໂຟລເດີ ແລ້ວທຽບກັບ URL ທີ່ໄດ້:

📁 app/
 └── 📁 pages/
      ├── 📄 index.vue      →  ເປີດເວັບຈະເຫັນໜ້ານີ້ກ່ອນ  (/)
      ├── 📄 about.vue      →  /about
      ├── 📄 contact.vue    →  /contact
      └── 📁 courses/
           ├── 📄 index.vue →  /courses
           └── 📄 [id].vue  →  /courses/1, /courses/2, ... (ໄດ້ໝົດ!)
ຊື່ໄຟລ໌ URL ທີ່ໄດ້ ຈື່ງ່າຍໆ
index.vue / index = ໜ້າຫຼັກສະເໝີ
about.vue /about ຊື່ໄຟລ໌ = ຊື່ URL
courses/[id].vue /courses/ຫຍັງກໍໄດ້ ວົງເລັບ [ ] = ຄ່າປ່ຽນໄດ້ (Dynamic)

🛠️ ລອງເຮັດເລີຍ: ສ້າງໜ້າ About ໃນ 2 ຂັ້ນຕອນ

1

ສ້າງໄຟລ໌ໃໝ່ຊື່ app/pages/about.vue ແລ້ວໃສ່ໂຄດນີ້:

<!-- app/pages/about.vue -->
<template>
  <div class="p-8 space-y-4">
    <h1 class="text-2xl font-bold text-white">ກ່ຽວກັບພວກເຮົາ</h1>
    <p class="text-slate-300">ນີ້ຄືໜ້າ About ທີ່ຂ້ອຍສ້າງເອງໃນ Nuxt 4!</p>
  </div>
</template>
2

ເປີດ Browser ໄປທີ່ http://localhost:3000/about — ສຳເລັດ! ບໍ່ຕ້ອງຕັ້ງຄ່າຫຍັງເພີ່ມເລີຍ 🎉

🔢 ໜ້າແບບ Dynamic: ໜ້າດຽວ ສະແດງໄດ້ຫຼາຍຂໍ້ມູນ

ສົມມຸດມີບົດຮຽນ 100 ບົດ — ຈະສ້າງ 100 ໄຟລ໌ບໍ? ບໍ່ຕ້ອງ! ສ້າງໄຟລ໌ດຽວຊື່ [id].vue (ມີວົງເລັບ) ແລ້ວອ່ານຄ່າຈາກ URL ມາໃຊ້: 

<!-- app/pages/courses/[id].vue -->
<script setup>
// useRoute() ໃຊ້ອ່ານຂໍ້ມູນຈາກ URL ປັດຈຸບັນ
const route = useRoute()
// ຖ້າເຂົ້າ /courses/5  →  route.params.id ຈະໄດ້ຄ່າ "5"
</script>

<template>
  <h1 class="text-xl font-bold text-white">ບົດຮຽນເລກທີ: {{ route.params.id }}</h1>
</template>
👉 ເຂົ້າ /courses/1 ຈະເຫັນ: ບົດຮຽນເລກທີ: 1
👉 ເຂົ້າ /courses/99 ຈະເຫັນ: ບົດຮຽນເລກທີ: 99

2 ເຊື່ອມແຕ່ລະໜ້າດ້ວຍ <NuxtLink>

ມີໜ້າແລ້ວ ກໍຕ້ອງມີລິ້ງໃຫ້ຜູ້ໃຊ້ກົດໄປມາ. ໃນ Nuxt ໃຫ້ໃຊ້ <NuxtLink> ແທນ <a> ທຳມະດາ:

❌ <a href> ແບບເກົ່າ

ກົດແລ້ວ Browser ຈະ Reload ໜ້າຈໍທັງໝົດ — ຈໍວັບ, ຊ້າ, ເສຍຄ່າ State ທີ່ຄ້າງໄວ້.

✅ <NuxtLink> ຂອງ Nuxt

ປ່ຽນສະເພາະເນື້ອຫາ ໄວທັນທີ ບໍ່ Reload — ຄືກັບແອັບມືຖື ລື່ນໆ.

<template>
  <nav class="flex gap-4">
    <NuxtLink to="/" class="text-teal-400 hover:underline">ໜ້າຫຼັກ</NuxtLink>
    <NuxtLink to="/about" class="text-teal-400 hover:underline">ກ່ຽວກັບ</NuxtLink>
    <NuxtLink to="/courses/1" class="text-teal-400 hover:underline">ບົດຮຽນທີ 1</NuxtLink>
  </nav>
</template>
💡 ຈື່ງ່າຍໆ: ລິ້ງພາຍໃນເວັບເຮົາ → ໃຊ້ <NuxtLink>, ລິ້ງໄປເວັບຄົນອື່ນ (ເຊັ່ນ google.com) → ໃຊ້ <a href> ຄືເກົ່າ.

3 Components: ຂຽນເທື່ອດຽວ ໃຊ້ໄດ້ທຸກໜ້າ ♻️

💡 ແນວຄິດງ່າຍໆ

Component ຄື ຊິ້ນສ່ວນ UI ທີ່ຕັດອອກມາເປັນໄຟລ໌ຂອງມັນເອງ ເຊັ່ນ ປຸ່ມ, ການ໌ດສິນຄ້າ, Navbar — ປຽບເໝືອນຕົວຕໍ່ Lego 🧱: ສ້າງຊິ້ນດຽວ ແລ້ວເອົາໄປຕໍ່ໃສ່ໜ້າໃດກໍໄດ້.

ຈຸດເດັ່ນຂອງ Nuxt: ໄຟລ໌ໃນ app/components/ ບໍ່ຕ້ອງ import ເລີຍ — ພິມຊື່ Tag ໃຊ້ໄດ້ທັນທີ!

❌ Vue ແບບປົກກະຕິ
import CourseCard
  from '~/components/CourseCard.vue'
// ຕ້ອງຂຽນແບບນີ້ທຸກໜ້າ ທຸກ component 😩
✅ Nuxt 4 (Auto-Import)
<CourseCard />
// ໃຊ້ໄດ້ເລີຍ! Nuxt import ໃຫ້ເອງ 😎

🛠️ ຕົວຢ່າງເຕັມ: ສ້າງການ໌ດບົດຮຽນ (CourseCard)

1

ສ້າງໄຟລ໌ app/components/CourseCard.vue — ຮັບຂໍ້ມູນຜ່ານ props (ຄືຊ່ອງສຽບຂໍ້ມູນ):

<!-- app/components/CourseCard.vue -->
<script setup>
// ປະກາດວ່າ Component ນີ້ຮັບຂໍ້ມູນຫຍັງແດ່
defineProps({
  title: String,   // ຊື່ບົດຮຽນ
  hours: Number    // ຈຳນວນຊົ່ວໂມງ
})
</script>

<template>
  <div class="p-5 rounded-2xl bg-[#0c1220] border border-slate-800 space-y-2">
    <h3 class="text-lg font-bold text-white">{{ title }}</h3>
    <p class="text-xs text-slate-400">ໄລຍະຮຽນ: {{ hours }} ຊົ່ວໂມງ</p>
  </div>
</template>
2

ເອີ້ນໃຊ້ໃນໜ້າໃດກໍໄດ້ ໂດຍບໍ່ຕ້ອງ import — ໃສ່ຂໍ້ມູນຕ່າງກັນໄດ້ແຕ່ລະອັນ:

<!-- app/pages/index.vue -->
<template>
  <div class="grid grid-cols-2 gap-4">
    <CourseCard title="ພື້ນຖານ Nuxt 4" :hours="3" />
    <CourseCard title="ຕິດຕັ້ງ Vuetify" :hours="2" />
  </div>
</template>
⚠️ ຂໍ້ຄວນຮູ້: ຖ້າ Component ຢູ່ໃນໂຟລເດີຍ່ອຍ ຊື່ Tag ຈະລວມຊື່ໂຟລເດີນຳ:
app/components/course/Card.vue → ໃຊ້ເປັນ <CourseCard />

4 Layouts: Navbar + Footer ອັນດຽວ ໃຊ້ທຸກໜ້າ 🖼️

💡 ແນວຄິດງ່າຍໆ

Layout ປຽບເໝືອນ ກອບຮູບ: ກອບ (Navbar + Footer) ຄືເກົ່າສະເໝີ, ປ່ຽນແຕ່ຮູບຂ້າງໃນ (ເນື້ອຫາຂອງແຕ່ລະໜ້າ). ດັ່ງນັ້ນເຮົາຂຽນ Navbar ເທື່ອດຽວ — ບໍ່ຕ້ອງ copy ໃສ່ທຸກໜ້າ.

ສ້າງໄຟລ໌ app/layouts/default.vue — ຊື່ default ໝາຍຄວາມວ່າທຸກໜ້າຈະໃຊ້ Layout ນີ້ອັດຕະໂນມັດ: 

<!-- app/layouts/default.vue -->
<template>
  <div class="min-h-screen flex flex-col bg-[#070b12] text-white">

    <header class="p-4 border-b border-slate-800">🔝 Navbar — ສະແດງທຸກໜ້າ</header>

    <main class="flex-grow p-6">

5 ສະຫຼຸບບົດຮຽນ 📝

ຢາກເຮັດຫຍັງ? ເຮັດແນວໃດ?
ສ້າງໜ້າເວັບໃໝ່ ສ້າງໄຟລ໌ .vue ໃນ app/pages/
ໜ້າທີ່ຮັບຄ່າຈາກ URL ຕັ້ງຊື່ໄຟລ໌ [id].vue + ອ່ານດ້ວຍ useRoute().params.id

ຊິ້ນສ່ວນ UI ໃຊ້ຊ້ຳ ສ້າງໄຟລ໌ໃນ app/components/ — ໃຊ້ໄດ້ເລີຍ ບໍ່ຕ້ອງ import
Navbar/Footer ທຸກໜ້າ ສ້າງ app/layouts/default.vue + ໃສ່ <slot />

  2. ສ້າງ Component app/components/MyButton.vue ທີ່ຮັບ prop ຊື່ label ແລ້ວເອົາໄປໃຊ້ 2 ໜ້າ
  3. ສ້າງ Layout default.vue ທີ່ມີ Navbar ພ້ອມ <NuxtLink> ໄປຫາ 3 ໜ້າ: ໜ້າຫຼັກ, About, Contact
  4. ທ້າທາຍ 🔥: ສ້າງ app/pages/students/[name].vue ໃຫ້ສະແດງ "ສະບາຍດີ {name}" ເມື່ອເຂົ້າ /students/somchai
